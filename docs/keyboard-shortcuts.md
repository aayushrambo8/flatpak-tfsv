# Keyboard Shortcuts

- `j` / Down: move selection down
- `k` / Up: move selection up
- `l` / Right: enter directory
- `h` / Left: move to parent directory
- `.`: show or hide hidden items
- Home / End: move selection to the first / last item
- Page Up / Page Down: move selection by a page
- `r`: refresh view
- `s`: cycle sorting mode
- `q` / Esc: quit
